# MindCanvas v0.1.0 Preview

MindCanvas v0.1.0 is the first public engineering preview of the WinUI 3 application.

## Highlights

- WinUI 3 / Windows App SDK desktop foundation
- Persistent document tabs with Home / Documents / Templates / Settings navigation
- Simplified Chinese, English, and Japanese resources
- `.mcanvas` native document model and persistence
- New / open / save / save as and undo / redo groundwork
- Initial map / outline rendering and right-logic layout
- Store / sideload-aware in-app update foundation
- Per-Monitor V2 high-DPI support
- Signed x64 and ARM64 MSIXBundle packages
- One-click ZIP installer packages with certificate, checksums, scripts, and localized instructions

## Design status

The approved Figma **V4** is the sole UI design source of truth. v0.1.0 establishes the runnable product architecture; v0.1.5 is reserved for a high-fidelity WinUI 3 implementation of V4.
