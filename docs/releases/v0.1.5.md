# MindCanvas v0.1.5 Preview

MindCanvas v0.1.5 is the high-fidelity WinUI 3 implementation of the approved Figma V4 interface.

## Highlights

- Unified V4 application shell with persistent document tabs and page-specific context actions.
- Home, Documents, Templates, Settings, Map, Outline, and Split views aligned to V4 geometry, spacing, color, typography, and control states.
- Seven distinct Settings categories: General, Language & region, Appearance, Editing, Files, Export, and About.
- Simplified Chinese, English, and Japanese parity across the shell and page content.
- Preserves the v0.1.0 `.mcanvas` document model, update infrastructure, Per-Monitor V2 DPI awareness, and release pipeline.
