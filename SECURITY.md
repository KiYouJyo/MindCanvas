# Security Policy

## Supported versions

MindCanvas is currently pre-1.0. Only the newest preview release is supported.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature when available, or contact the repository owner privately.

## Distribution trust

Official GitHub packages are expected to be signed with the configured MindCanvas publishing certificate. One-click packages include SHA-256 checksums. Microsoft Store installations use Store-managed signing and update delivery.
